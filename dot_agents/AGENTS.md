# Global Operating Rules

- Respond in Japanese. Keep this file in English.

# Development Style

- Follow TDD: Explore → Red → Green → Refactor.
- When given KPI or coverage targets, iterate until they are met.
- Ask to clarify unclear instructions.

# Code Design

- Maintain separation of concerns.
- Separate state from logic.
- Prioritize readability and maintainability.
- Define the contract layer (APIs/types) strictly; keep the implementation layer regenerable.
